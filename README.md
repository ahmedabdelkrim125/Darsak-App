## عن التطبيق

**درسك** هو تطبيق لإدارة العملية التعليمية اليومية بطريقة بسيطة ومرتبة. صُمم ليكون المساعد الرقمي للمعلم في تنظيم الحصص، إدارة المجموعات والطلاب، مشاركة المحتوى، وتسجيل المدفوعات، مع تجربة عربية واضحة ومريحة.

الفكرة الأساسية بسيطة: بدلًا من توزيع تفاصيل العمل الدراسي بين أكثر من أداة، يجمعها درسك في تجربة واحدة تساعدك على التركيز على ما يهم فعلًا: **تقديم درس أفضل ومتابعة تقدم طلابك.**

## لماذا درسك؟

| للمعلم | للطالب |
| --- | --- |
| إدارة الحصص والمواعيد بسهولة | متابعة الحصص والمواعيد |
| تنظيم الطلاب داخل مجموعات | الوصول إلى تجربة تعليمية أوضح |
| تسجيل المدفوعات ومتابعتها | تلقي التذكيرات والتنبيهات |
| رفع الملفات والمحتوى التعليمي | تنظيم الدراسة والمهام |

## المميزات الرئيسية

### لوحة تحكم ذكية

- ترحيب شخصي وملخص سريع لليوم الدراسي.
- عرض حصص اليوم مع حالة واضحة عند عدم وجود حصص.
- اختصارات مباشرة لإضافة حصة أو مجموعة أو طالب.
- الوصول السريع إلى أحدث الملفات والمحتوى.
- تنبيهات مدمجة لمتابعة المستجدات المهمة.

### إدارة الجدول والحصص

- عرض الجدول بطريقة أسبوعية أو شهرية.
- التنقل بين الأيام والتواريخ بسهولة.
- إضافة الحصص وتعديل مواعيدها من نفس المسار.
- عرض تفاصيل الحصة والطلاب المرتبطين بها.
- تصميم يساعد على رؤية اليوم الدراسي دون ازدحام بصري.

### إدارة المجموعات والطلاب

- إنشاء مجموعات تعليمية وتنظيمها حسب المرحلة.
- إضافة الطلاب وربطهم بالمجموعات المناسبة.
- عرض تفاصيل المجموعة والطلاب التابعين لها.
- البحث والتصفية للوصول إلى المعلومات بسرعة.
- إجراءات منفصلة لإضافة وإدارة الطلاب والمجموعات.

### متابعة المدفوعات

- تسجيل الدفعات لكل طالب.
- عرض المدفوعات حسب الطلاب أو المجموعات.
- حالات واضحة: مدفوع، مدفوع جزئيًا، ومتأخر.
- ملخصات تساعد المعلم على فهم الوضع المالي بسرعة.
- البحث والتصفية للوصول إلى سجل محدد دون تعقيد.

### المحتوى والملفات

- رفع ومتابعة الملفات التعليمية.
- دعم عرض أنواع متعددة من المحتوى مثل PDF وMP4 والصور.
- بطاقات واضحة لاسم الملف ونوعه وحجمه.
- تنظيم الملفات ضمن تجربة واحدة مرتبطة بالحصة والعمل الدراسي.

### حساب وتجربة شخصية

- اختيار نوع الحساب: معلم أو طالب.
- تسجيل الدخول وإنشاء حساب جديد.
- استعادة كلمة المرور عبر خطوات واضحة.
- تعديل الملف الشخصي وإدارة الإعدادات.
- دعم الإشعارات واللغة والتواصل والمساعدة.

## التقنيات المستخدمة

- **Flutter / Dart** لبناء تطبيق متعدد المنصات.
- **Material 3** لتجربة واجهة حديثة قابلة للتخصيص.
- **flutter_bloc** لإدارة حالات الشاشات وتدفق البيانات.
- **Dio + Retrofit** للتعامل مع خدمات الشبكة.
- **GetIt** لحقن الاعتمادات وتنظيم الخدمات.
- **Shared Preferences** لحفظ الإعدادات المحلية.
- **Flutter Secure Storage** لحماية بيانات الجلسة.
- **Connectivity Plus** لمتابعة حالة الاتصال.
- **IBMPlexArabic** لتقديم قراءة عربية مريحة ومتناسقة.

## تنظيم المشروع

```text
lib/
├── core/
│   ├── config/       إعدادات البيئة
│   ├── network/      الشبكة والجلسات والأخطاء
│   ├── routing/      التنقل والمسارات
│   ├── theme/        الألوان والخطوط والمظهر
│   └── widgets/      عناصر واجهة قابلة لإعادة الاستخدام
└── feat/
    ├── auth/         الدخول والتسجيل واستعادة كلمة المرور
    ├── classroom/    إدارة الحصص والطلاب
    ├── groups/       إدارة المجموعات
    ├── home/         لوحة التحكم الرئيسية
    ├── main/         التنقل الرئيسي
    ├── more/         الملف الشخصي والإعدادات والمساعدة
    ├── notification/ التنبيهات
    ├── onboarding/   شاشات التعريف بالتطبيق
    ├── payments/     المدفوعات
    ├── role_selection اختيار نوع الحساب
    ├── schedule/     الجدول الدراسي
    └── splash/       شاشة البداية
```

## التشغيل محليًا

### الخطوات


لإنشاء نسخة Android:
